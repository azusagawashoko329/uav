# 外观分支创新点②:层注意力适配器(LAA)

把外观分支人工选的固定 taps `[5,7,9,11]` 换成**对全 12 个 DINOv3 block 学习的一套 per-scene 权重 `w=softmax(logits)`**。教师↔学生反向一一对齐与 top-k 读出不变,`w` 只决定每层的对齐损失/打分占多少;`w` 由**输入图伪异常**驱动、对重建路径断梯度(不作弊、不碰 test)。目的:为投更好期刊补模块级创新点(允许零增益/略降)。

- **variant B(定稿)**:OCBE 输入 = 全 12 层 concat(`w` 不碰输入),`w` 只加权 loss/打分。`w` 实际收敛到**近均匀(略偏中后层)**——原始逐层 gap 是极小绝对余弦差,`softmax` 近均匀;等价于"全 12 层近均匀可学聚合"。
- 实现:`model/adapter.py`(`LayerAttnAdapter`)、`model/loss.py`(`per_layer_topk_dist`/`adapter_objective`/`anomaly_readouts_weighted`)、`train.py --tap_adapter --pseudo`、`eval.py` 自动识别。产物 `experiment_LAA/20260624_uniform_ref/`。

## 表1 — 外观单分支 AUC(concat-micro topk,vs 手选 4-tap 基线)
| 场景 | 基线 4-tap | LAA-B |
|---|--:|--:|
| highway | 92.34 | 96.08 |
| farmland | 99.40 | 99.27 |
| bike | 98.08 | 97.64 |
| solar | 87.21 | 89.11 |
| vehicle | 60.54 | 64.96 |
| crossroads | 59.72 | 60.54 |
| railway | 94.94 | 92.84 |
| **均值(mAUC)** | **84.60** | **85.78 (+1.18)** |

> 7 场景 mAUC,单场景互有涨跌属正常;**+1.18 来自"全 12 层可学聚合"替代人工选 4 层**(自动化、去人工超参)。`w` 收敛近均匀(展开 0.001–0.002,top 一致落中后层 L5–L10)→ 佐证"中后层都有贡献、`[5,7,9,11]` 是合理但非必要的人工选择"。

## 表2 — 消融:激进选层(z-score 标准化 gap)反而更差
| 场景 | LAA-B(近均匀) | z-score(强选层) |
|---|--:|--:|
| highway | 96.08 | 93.90 |
| farmland | 99.27 | 99.52 |
| bike | 97.64 | 97.84 |
| solar | 89.11 | 87.54 |
| vehicle | 64.96 | 54.27 |
| crossroads | 60.54 | 59.85 |
| railway | 92.84 | 93.19 |
| **均值** | **85.78** | **83.73 (−2.05)** |

> 把 gap 标准化后 `w` 真拉开(展开 0.01–0.1、按场景特化),但 AUC 反降,**主因 vehicle −10.7**(外观-null 场景,局部-patch 伪异常先验不匹配其真异常=违停)。去掉 vehicle:z-score 88.64 ≈ 基线 88.62(中性)。结论:**近均匀聚合 > 激进选层**,故 variant B 定稿。(产物 `experiment_LAA/20260625_laa_zscore/`。)

## 表3 — 融合(LAA 外观 + 行为分支,门控 `w=0.5·q·(1−2|pa−0.5|)^γ`,γ=1)
| 场景 | LAA外观 | 行为 | q | 融合(γ=1) |
|---|--:|--:|--:|--:|
| highway | 96.08 | 46.86 | 1.000 | 94.49 |
| farmland | 99.27 | 49.67 | 0.068 | 99.27 |
| bike | 97.64 | 56.00 | 0.345 | 96.91 |
| solar | 89.11 | 48.29 | 0.108 | 89.09 |
| vehicle | 64.96 | 71.86 | 1.000 | 70.15 |
| crossroads | 60.54 | 51.85 | 0.946 | 58.81 |
| railway | 92.84 | 49.69 | 0.050 | 92.84 |
| **均值** | **85.78** | | | **85.94 (+0.16)** |

**门控 γ 敏感性(统一应用、未挑场景)**:γ=1.0 → **85.94**;γ=1.5 → 85.87;γ=2.0 → 85.84。**γ=1 最优,定为默认**(调高 γ 救 highway/crossroads 但削 vehicle,净降;且先验 γ=1 自胜,无调参泄露嫌疑)。

> **LAA + 融合 = 85.94 是当前最高**(vs 旧 DABG 融合 85.75)。LAA 把外观抬强后融合增益变小(+0.16,旧版 +1.15),因为强外观让门控留给行为的空间变小;highway 此版被融合略拖(−1.59)是 vehicle +5.19 的对价(同一旋钮此消彼长)。可作 limitation 照实写。

## 结论
- 创新点② 定稿 = **LAA variant B(近均匀全层可学聚合)**:外观 mAUC 85.78(+1.18 vs 手选 4-tap),融合 85.94。
- 自带两条干净消融:**z-score 强选层 −2.05**(反证近均匀设计)、**门控 γ 敏感性**(γ=1 最优)。
- 待续:variant A(`w` 也聚合 OCBE 输入)消融;创新点③ 学生轻量化。
