## 开发大图(一页纸)

```
诊断: 异常类型 × 归纳偏置错配, 外观/运动两族互补反相关
  │
  ├─ 外观分支(RD) ──────────────────────────────────────────────┐
  │   复现MADViT → 逐层(L5-L8) → 轮次(ep15) → top-k(LLTopk)       │
  │   → 自建RD(DINOv3+OCBE+学生+top-k) → 消融(top-k价值在读出端)   │  晚融合
  │   → 教师消融(增益来自方法+10.3) → 均值 84.67                   ├─(检测质量q门控)→ 85.75
  │                                                               │
  └─ 行为分支 ───────────────────────────────────────────────────┘
      外观在vehicle/crossroads哑火 → 教师时序探针(全跌破随机,否)
      → 运动建模设想 → 发现交互无需时序 → 退化成单帧
      → 检测+5描述子(3→5)+kNN-OOD, 无参数 → vehicle 72.60
```

## 最终成绩(7 场景 frame-level AUC%)

| | highway | farmland | bike | solar | vehicle | crossroads | railway | **均值** |
|---|---|---|---|---|---|---|---|---|
| 单分支·外观 | 92.31 | 99.40 | 98.08 | 87.29 | 60.54 | 59.70 | 94.93 | **84.61** |
| 单分支·行为 | 48.61 | 49.67 | 55.82 | 48.29 | **72.60** | 54.78 | 49.69 | — |
| **门控融合** | 93.60 | 99.40 | 97.40 | 87.26 | **68.76** | 58.88 | 94.93 | **85.75** |

> **全部以 DABG 正式版为准**(`experiments/20260617_all_model/`,统一 seed=42):外观 **84.61** → 门控融合 **85.75(+1.14)**;行为单分支仅 vehicle(72.60)有真信号、其余 ≈50 被 q 门控静默。完整 SOTA 对比见 [方法对比总表](方法对比总表.md)。
> 外观分支**开发实验**另用专门 baseline `20260611_rd_baseline`(均值 84.67,solar/railway 有单 seed run 方差 ±1),消融/教师/benchmark 见外观日志——那是外观研究口径,与此处交付口径(DABG 84.61)是两次独立训练,差异在单 seed 方差内。
