# LAA(层注意力适配器)研究全过程

外观分支的第二个模块级创新点。本文档记录从动机、想法、踩坑、实验到最终拍板的完整脉络。

---

## 1. 动机:组会要"凑创新点"
两个数据集(Drone-Anomaly SOTA、UIT-ADrone 次SOTA)表现与消融都已充分,但**创新性单薄**:该领域多数对比方法是**框架级**创新,我们的双分支门控融合框架够新,可**模块级**能被引用的只有 top-k 读出一个。为投更好期刊,需再补 1–2 个模块级创新点。**前提:创新点不必带来提升,略降也可接受,目的是"凑点"+ 有可写、可消融、可画图的贡献。**

## 2. 出发点:现有外观分支(反向蒸馏 RD)
- 冻结 DINOv3 ViT-B/16 教师 → 取若干层 patch 特征;
- OCBE 瓶颈(code_dim=64)把这些层挤压;
- student 解码器重建教师特征,逐层反向一一对齐;
- 每 patch 余弦距离 → **层内 top-k(k=5)** 挑最难 patch → 帧级异常分。
- **痛点**:tap 层是**人手固定 [5,7,9,11]**(基于"中后层判别力强"的经验),是个人工超参,且"中后层"结论很笼统——不同场景敏感的层并不同。

## 3. 核心想法:LAA
把人手选层换成**对全 12 层学习的一套 per-scene 权重 `w = softmax(logits)`**:
- 教师↔学生反向一一对齐、top-k 全不变;
- `w` 决定每层的对齐损失/打分占多少(layer 轴);top-k 仍管 patch 轴。两轴正交;
- `w` 由**输入图伪异常**驱动(哪层对局部破坏最敏感→权重高),不碰 test。
- 卖点:**自动、按场景的全层可学聚合**,替代人工选层。

## 4. 关键设计决策(踩坑 → 对策)
1. **塌缩陷阱**:若让 adapter 重定义"蒸馏目标",优化器会把目标压成平凡子空间、loss→0 但判别力归零。
   → **目标始终是各层冻结的原始教师特征,`w` 只加权不重定义** → 不塌。
2. **作弊陷阱(对齐≠检测)**:若 `w` 由"最小化正常重建"来定,会漂向**易重建但没判别力的浅层**(all-tap 实验佐证)。
   → **`w` 只由伪异常选层信号训练,在重建路径上全程 detach**;两条梯度子图(重建训 student/OCBE、选层训 `w`)互不交叉。
3. **伪异常怎么造**:加在**输入图像**(绝不加在教师特征上=循环论证),且**局部温和**——随机一半样本、1–2 个 16×16 patch 块做**涂白/涂黑/模糊/同帧对调**。两正常/伪异常帧走同一冻结管线,逐层 gap `g_l = t̃_l − t_l`(对 batch 均值)→ `KL(softmax(g/τ)‖w)` 推 `w`,熵正则防塌。
4. **变体 A vs B(`w` 用在哪)**:
   - **B**:OCBE 输入=全 12 层 concat,`w` 只加权 loss/打分(输入平稳、信息全);
   - **A**:`w` 也聚合 OCBE 输入(12 层→单 768,n_taps=1)。
5. **选层强度(z-score)**:原始 gap 是极小绝对余弦差(~1e-3),`softmax(g/1)≈均匀` → `w` 近均匀。试过把 gap **z-score 标准化**让 `w` 强行拉开(展开 0.01–0.1、按场景特化)。

## 5. 一个训练 step 怎么走
取正常 batch `x` → 造 `x̃=perturb(x)` → 两者各过同一冻结 teacher→OCBE→student → 逐层 top-k 距离 `t_norm`/`t_pseudo` →
`L_normal=Σ w.detach()·t_norm`(训 student/OCBE)+ `L_select=KL(softmax(g/τ)‖w)`(g detach,只训 `w`)+ `L_ent` 熵正则。
`L_select` 对 logits 的梯度恰为 `w−target`,梯度下降把 `w` 推向 `target=softmax(gap)`,即敏感层权重升高。伪异常那行只前向、不反传(白建图,可 no_grad 提速)。

行为分支(冻结 YOLO+kNN)三版本共用同一份预存逐帧分;融合门控 `w=0.5·q·(1−2|p_app−0.5|)`,γ=1。

## 7. 关键发现与最终拍板
**排序:LAA-B(85.78/85.94)> 基线(84.60)> z-score(83.73/84.21)> LAA-A(82.82/82.96)。** 三点结论:
- **只有 LAA-B 超过基线**(外观 +1.18、融合 +1.34 vs 基线外观,且 85.94 > 旧 DABG 融合 85.75)。
- **变体 A 最差(−1.78)**:把 12 层 `w` 聚合压成单视图喂瓶颈,**丢了信息**(railway 92.84→90.59、vehicle 64.96→48.50 跌到随机以下)。→ **结论:别把 `w` 折进输入,保留 12 层 concat 让瓶颈自己挤。**
- **z-score 次差(−0.87)**:`w` 强行拉开后,在**外观-null 的 vehicle 上 −10.7**(64.96→54.27)——局部-patch 伪异常先验不匹配它的真异常(违停/时序停驻),选层被带偏。→ **结论:近均匀聚合 > 激进选层。**

两个消融从两个方向夹逼:**输入别压、选层别狠** → **最终拍板 LAA-B(全 12 层 concat + 近均匀可学 `w`)**。

**为什么 B 的 `w` 近均匀反而最好**:它等价于"all-tap 骨干 + 一个学出来、近均匀、按场景微调的逐层权重",既用满了 12 层(比手选 4 层 +1.18),又没有 A 的信息损失、没有 z-score 的误选。

**融合侧观察**:三版本融合都靠行为救 vehicle(外观-null,beh 71.86);外观越强(B),门控留给行为的空间越小、融合增益越小(B +0.16、zscore +0.48),但绝对值 B 融合 85.94 最高。门控 γ 敏感性(85.94/85.87/85.84 @ γ=1/1.5/2)显示 γ=1 已最优、无需为冲分调参(避免 test 泄露)。

## 8. 诚实的论文口径
- 创新点② = **可学习的全 12 层聚合 adapter**(自动、按场景),比手选 4-tap **+1.18 外观 / +1.34 融合**;
- `w` 收敛**近均匀(略偏中后层)** → 佐证"中后层都有贡献、手选 [5,7,9,11] 是合理但非必要的人工选择";**卖点是"可学/自动 vs 人工",不是"强选层"**;
- 两条自洽消融:**变体 A(压输入)−1.78、z-score(强选层)−0.87** → 正好反证 B 的设计选择(输入不压、选层温和);
- limitation:伪异常是"异常长什么样"的先验,对真异常≠局部外观破坏的场景(vehicle 违停)会误导选层——但那类场景外观本就无能为力,交给行为分支。

## 9. 工程落地(同步回 DABG)+ 权威数(seed=42)
LAA-B 已移植进正式版 `DABG`(flag 默认关=历史固定 tap,版本兼容):`model/appearance/adapter.py` + loss 4 函数 + runner `score_video(adapter=)`;`fusion/{train_fusion,eval_fusion,eval_eer,run_all}.py` 接 `--tap_adapter --pseudo`;`model/behavior/features.py` 的 det_cache 改 `det_cache/<split>/<scene>/`(train/test 物理隔离)。

**权威结果以 seed=42 的完整从头跑为准**(`DABG/experiments/20260625_LAA_b`,15ep、双卡动态、两分支、无旧缓存、cudnn.deterministic):

| | 外观 mAUC | 融合 mAUC |
|---|--:|--:|
| **DABG LAA-B(seed42,权威)** | **85.24** | **85.73** |
| 固定 4-tap 基线(20260617,seed42) | 84.61 | 85.75 |
| uav 参照 B(未固定 seed 的单次抽样) | 85.78 | 85.94 |

- **同 seed42 下,固定 4-tap 84.61 → LAA 85.24(+0.63),融合 85.75→85.73(≈持平)**。⚠️**诚实地讲,这 +0.63 在单 seed 的 run 方差内、不可主张为稳健增益**:LAA 的 w 收敛**近均匀**(spread~0.001),功能上 ≈ all-tap(全 12 层均匀),与固定 4-tap 的差异主要来自训练随机性——逐场景 highway +3.6 / railway −2.6 这种反向大幅抖动正是种子方差的特征(若"用满12层"系统性更好,应一致正向)。当年"all-tap −0.6"同理很可能是种子运气。**要判定真实增益必须多 seed**(fixed-4tap / all-tap / LAA 各 ≥3 seed 看 mean±std)。
- 因此 **adapter 的贡献定位在方法层面,不在 AUC**:① 去掉人工选层超参(auto、per-scene);② 可解释的逐层权重(见 [LAA_层敏感统计.md](LAA_层敏感统计.md));③ 两条真实否决消融(变体 A −1.78、z-score −0.87)。论文口径应为"**可学层聚合,匹配人工/all-tap 性能、去超参、可解释**",**不主张 AUC 增益**(除非补多 seed)。
- 第 6 节三版本对比表(85.78/85.94 等)是 **uav 未固定 seed 的内部 A/B/zscore 对照**(同条件可比);**对外/论文引用一律用上表 seed42 的 85.24/85.73**,uav 的 85.94 只是另一次抽样(±0.5 run 方差内)。**不为凑 85.94 挑 seed**。
- 逐场景 AUC/EER 出处:`DABG/experiments/20260625_LAA_b/{results_fusion,results_eer}.csv`。
