# OCBE 隐藏维度 128：保留原有融合结构

## 研究问题

在 [192 维 Global-Local 学生基线](../20261012_student_width192_glll_s42/README.md)中，可训练总参数 7,718,336，其中 OCBE 为 4,770,368（61.81%）。OCBE 的第一层把同一 patch 的 12×768 维教师特征拼接后映射至 512 维，占 OCBE 的绝大多数参数。本实验只把该隐藏维度从 512 改为 128，测试最简单的参数压缩是否保留七场景 AUC。

## 唯一变化

OCBE 继续对 12 个教师 tap 分别做仿射 LayerNorm，再拼接并执行 `Linear(9216, H) → GELU → Linear(H, 64)`。本变体仅设 `H=128`。冻结 DINOv3 ViT-B/16、学生四个 Global-Local block（内部维度 192）、12 个输出头 `192→768`、每相邻三层教师对一层学生的反向对齐、group-balanced top-5 cosine loss 均不变。

参数公式为 `12×2×768 + (9216+1)×H + (H+1)×64`。`H=128` 时 OCBE 为 **1,206,464**，与学生 2,947,968 合计 **4,154,432**，相比原 192 维配置减少 **46.17%** 可训练参数。最终 code_dim=64 不变，异常无法通过一个更宽的末端 code 直接泄漏给学生。隐藏层缩窄可能限制正常模式拟合，AUC 需要实测。

## 固定训练与评测

- Drone-Anomaly 七场景独立训练，seed=42；正常帧训练，15 epoch，batch=64，图像 256×256；AdamW、OneCycleLR、max_lr=5e-4、weight_decay=0.05。
- 测试分数为12个重建头的 top-5 patch cosine distance 平均，越大越异常。场景内拼接逐帧分数与 `.npy` 标签后算 ROC AUC×100，七场景做宏平均。与192维基线逐帧键、标签、数据指纹配对核验。
- 双卡动态调度：每张卡初始一个场景，结束后立即领取剩余队列中的下一个；轮询间隔2秒。

## 评估重点与限制

比较七场景宏平均、最差场景下降、参数量及训练损失方向。AUC 与重建 loss 可能不一致，不能只看 loss。单种子结果不能证明稳健改进；教师冻结参数和行为分支不计入上述可训练参数。

## 七场景结果与复盘

**观察值：**七场景均完成 15 个 epoch，调度器记录七次零返回结束；逐帧分数复算、标签键和数据划分指纹均与原 192 维配置一致。宏平均 AUC 为 **82.6137**，原配置为 **82.5381**，差 **+0.0756** 个百分点。OCBE＋学生参数为 **4,154,432**，比原配置少 **46.17%**。Railway 下降 **0.8094** 个百分点，是本次最大逐场景下降；Crossroads 上升 **1.1611** 个百分点。完整逐场景表和复核字段见 [结果报告](results/summary.md)、[机器可读结果](results/summary.json)。

**推断：**本次单种子结果支持把 OCBE 隐藏维度从 512 压到 128 作为轻量化候选：参数降幅大，宏平均 AUC 没有出现明显下降。**+0.0756** 个百分点不应解释成可信的 AUC 提升，也不能据此判定所有场景都无损。

**限制：**仅 seed=42，未测跨种子方差；Railway 下降仍需复核。这里的参数量不含冻结教师、YOLO 行为分支和 KNN 数据库，也没有无人机硬件上的端到端时延结果。
