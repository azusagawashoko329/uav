# OCBE 三层组内深度秩 2 融合：隐藏维度 128

## 研究问题

192 维 Global-Local 基线的 OCBE 需要把同一 patch 的 12×768 教师特征直接送入一个 512 维全连接层；这层约占 OCBE 的 99%。只缩小隐藏层虽能减参，仍为每个教师层单独学习一整套 768 通道映射。本实验进一步利用**既有的每相邻三层教师对应一层学生**的组结构，在每组三层中保留两个深度方向，再进行可学习通道融合；与同为隐藏维度128的[直接拼接对照](../20261013_ocbe_hidden128_dense_s42/README.md)比较 AUC 和参数量。

## 结构和数学推导

对每个 patch、每个教师组 `g`，先对三个 768 维 tap 分别应用与基线相同的仿射 LayerNorm，写成 `X_g∈R^(3×768)`。固定正交的深度基为

```text
q₀ = (1, 1, 1) / √3         组内共同模式
q₁ = (-1, 0, 1) / √2        从浅到深的变化模式
Q = [q₀; q₁],  QQᵀ = I₂
Z_g = Q X_g ∈ R^(2×768)
```

四组的 `Z_g` 拼接成 6144 维，再做 `Linear(6144,128) → GELU → Linear(128,64)`。该操作逐 patch 独立，不混合空间位置；最终 `code_dim=64` 不变，学生和蒸馏损失也不变。相较直接拼接，唯一新增的结构约束是舍弃每组三层的二阶深度弯曲方向 `q₂=(1,-2,1)/√6`。

令原第一层矩阵为 `W∈R^(128×9216)`，`P=blockdiag(QᵀQ⊗I₇₆₈,...,QᵀQ⊗I₇₆₈)`。存在一个仅作用于6144维压缩输入的矩阵 `W'=W·blockdiag(Qᵀ⊗I₇₆₈,...)`，使 `W'Z=WPX`。因此结构压缩在原线性层前的误差满足 `‖WX−W'Z‖₂ ≤ ‖W‖₂‖(I−P)X‖₂`；经过 GELU 和输出线性层后还会乘上相应的 Lipschitz/算子范数。这个上界只说明**当组内被舍弃的深度能量小时**，原融合函数可能被近似；它不保证异常检测 AUC。

在先导检查中，从七个场景各抽4张正常帧、对教师输出按通道做无仿射 LayerNorm 后，固定 `q₀/q₁` 的组内能量保留率约为 **89.2%–97.1%**。最深组三层的丢失最多，因此不能简单把三层平均成一层。正式训练前将用本目录脚本对每场景16帧复测；此诊断只使用正常训练帧，不使用异常标签。跨深度聚合的动机与 [DenseFormer 的深度加权聚合](https://arxiv.org/abs/2402.02622)有关；保留窄 code 以限制异常信息直接穿过学生则沿用[反向蒸馏 OCBE 的设计](https://openaccess.thecvf.com/content/CVPR2022/html/Deng_Anomaly_Detection_via_Reverse_Distillation_From_One-Class_Embedding_CVPR_2022_paper.html)。这些论文不替代本任务实证。

16 帧复测已经完成，七场景四组的固定基能量保留率为 **89.23%–97.11%**，详见 [正常特征诊断](results/depth_energy_probe.json)。这仍只是正常特征的投影能量，不是异常检测性能证据。

参数公式为 `12×2×768 + (6144+1)×128 + (128+1)×64`。OCBE 为 **813,248**，与固定的192维学生 **2,947,968** 合计 **3,761,216**；相比192维原始配置减少 **51.27%**，相比同隐藏维度的直接拼接对照再少 **393,216** 个参数。

## 固定训练与评测

- 冻结 DINOv3 ViT-B/16，12个教师 patch tap；OCBE tap LayerNorm、code_dim=64、192维 Global-Local 学生、12个 `192→768` 重建头、三对一反向对齐、group-balanced top-5 cosine loss 均保持不变。
- Drone-Anomaly 七场景独立训练，seed=42；正常帧训练，15 epoch，batch=64，图像256×256；AdamW、OneCycleLR、max_lr=5e-4、weight_decay=0.05。
- 测试分数为12个重建头的 top-5 patch cosine distance 平均，越大越异常。场景内拼接逐帧分数与 `.npy` 标签后算 ROC AUC×100，七场景做宏平均；与192维基线逐帧键、标签、数据指纹配对核验。
- 双卡动态调度：每张卡初始一个场景，结束后立即领取剩余队列中的下一个；轮询间隔2秒。

## 风险与判读

深度秩2仍会舍弃约3%–11%的正常特征能量，且这些方向的异常判别价值未知。若 AUC 明显下降，即使参数更少也不能称该结构有效。应报告七场景宏平均、逐场景最差下降和与隐藏维度128直接拼接的差异；单种子结果不能证明稳健性。

## 七场景结果与复盘

**观察值：**七个场景均完成 15 个 epoch，调度器记录七次零返回结束；逐帧分数复算、帧键、标签和数据划分指纹均与两个对照一致。宏平均 AUC 为 **82.7351**，原 192 维配置为 **82.5381**，直接拼接且隐藏维度 128 的对照为 **82.6137**。本结构的 OCBE＋学生可训练参数为 **3,761,216**，分别比两者少 **51.27%** 和 **9.46%**。完整逐场景结果见 [七场景报告](results/summary.md) 和 [机器可读结果](results/summary.json)。

**场景取舍：**相对直接拼接 128 维对照，Railway 的 AUC 高 **2.1571** 个百分点，Crossroads 和 Vehicle 分别低 **1.2797**、**1.0173** 个百分点；相对原 192 维配置，最大下降为 Vehicle 的 **0.2401** 个百分点。原 192 维配置在七场景的最终训练 loss 均低于本结构，但宏平均 AUC 略低；这再次说明当前重建 loss 与 AUC 不呈简单单调关系，不能从这个观察推出梯度冲突的机制结论。

**推断：**以本次 seed=42 的宏平均 AUC 与参数量共同看，深度秩 2 是值得保留的轻量化候选，而非已证实的稳定 AUC 提升。正常特征的秩 2 能量保留只支持结构设计；实际 OCBE 的 LayerNorm 仿射参数会在训练中更新，异常特征也可能落在被舍弃的弯曲方向。

**限制：**没有跨种子方差或目标无人机硬件上的端到端时延。七场景分别训练、分别测试，不能依据本次测试 AUC 事后为各场景选择结构并将其当作无偏评估。参数量不含冻结教师、YOLO 行为分支和 KNN 数据库。
