# 教师深度信息保留约束：随机正交起点，seed42

本实验与[固定 Mean+Trend 起点](../20261014_depthretain_fixedinit_h128_s42/README.md)构成同一问题的配对对照。**唯一变量是共享可学习 Q 的初始化**：这里使用独立 CPU 生成器、seed42 抽样的随机正交 `2×3` 基；除 Q 外的学生与 OCBE 初始权重保持一致。七场景独立训练，每场景与固定起点版本在同一 GPU 上先后运行。

两版均先用每场景 16 张正常帧的教师三层特征 `3×3` Gram 矩阵训练 Q 200 步，再以原蒸馏损失加 `1.0×L_retain` 联合训练 15 epoch；联合训练时每个 batch 从该场景实际正常训练帧的冻结教师特征计算 `C`。`L_retain=1−tr(Q_eff C Q_effᵀ)/tr(C)`；`Q_eff` 每次前向保持两行正交。训练、测试标签及 AUC 口径详见配对实验 README。比较的是二维**行子空间**而非单行符号或旋转；七场景终点是否相距 ≤5°、AUC 是否受损均待运行结果决定。

信息保留是明确的正常特征代理目标，并非异常 AUC 代理。16 张正常帧的 Q 预训练统计量、单个随机起点、下游权重共同训练是本实验的限制；失败或负结果保留。

## 结果与复核（2026-10-14）

详见[七场景配对结果](results/summary.md)。随机初值版宏平均帧 AUC 82.5673，比旧随机 Q 82.9599 低 0.3926 个百分点；与固定初值版最终 Q 平面平均只差 0.0028°，但逐场景 AUC 的平均绝对差仍为 0.6194 个百分点。六个 Q 数值并未逐个收敛，因为同一二维平面可用不同正交行基表示；下游融合权重与行坐标的共同优化仍有待隔离。
