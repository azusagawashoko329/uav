# Nonlinear Cross-Depth Mixer + Learnable Group Rank2

## 研究问题

LCDB验证了跨组先混合比DGT更稳定，但固定Mean＋Trend本身不够构成结构设计。本实验进一步学习四个教师组之间的关系，同时保持轻量化。

## 结构

Q仍在每组三层教师内部完成`3×768→2×768`。得到`Z[B,P,4,2,768]`后，使用零初始化的共享`A∈R^(4×4)`做非线性跨组残差：

`U = Z + GELU(A Z)`

随后使用可学习、行正交的`P∈R^(2×4)`把四个组压成两个跨组模式：

`V = P U`

最后将`V[B,P,2,2,768]`展平为3072维，经过`3072→128→64`。A和P分别作用在组关系轴和组压缩轴，不重复Q的组三层压缩；没有gate、1-hop、2-hop或额外主损失。P只在训练前向中做可微正交化，推理前缓存Q，避免重复执行。

## 固定设置

七场景独立训练，seed42，15 epoch，batch64，GL192学生，原三对一对齐和group-balanced top-k loss。两张卡动态调度，完成后比较AUC、参数、FLOPs、Latency和FPS。

## 预期判据

若AUC没有超过LCDB且速度不接近Rank2，则停止继续扩展跨组结构；若AUC恢复同时维持轻量化，则作为DGT后续的正式候选。
