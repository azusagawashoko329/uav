# Global-Local 学生内部维度 384 实验

## 研究问题

768 维 Global-Local 学生的七场景宏平均逐帧 AUC 为 84.773522，192 维实验为 82.538108。本实验只把同一结构的学生内部维度设为 **384**，检验中间宽度的 AUC 与参数量折中。主对照是 [768 维实验](../20261012_structural_mixer_glll_s42/README.md)，192 维结果只作为参考。

## 唯一变化与形状适配

- 学生输入投影、1 个全局 MHSA block、3 个局部 DWConv+Pointwise block 及 gated FFN 的内部维度为 384；stage 次序、8 个 attention heads、FFN ratio=2 保持不变。
- 12 个重建头从 `768→768` 变为 `384→768`，输出仍逐层对应 768 维教师特征。这是保证原损失可计算的必要形状适配；loss 形式、三对一反向对齐、异常分数公式均不变。
- 冻结 DINOv3 ViT-B/16 的 12 个 patch 输出和 OCBE（12 taps、code_dim=64）不变，无 adapter。

## 固定训练与评测

- Drone-Anomaly 七场景独立训练与测试，不混合权重；正常帧训练，seed=42，15 epoch，batch=64，图像 256×256。
- AdamW，OneCycleLR，max_lr=5e-4，weight_decay=0.05；group-balanced top-5 cosine loss，alpha=0.5。
- 每帧异常分数为 12 个重建头 top-5 patch cosine distance 的平均，分数越大越异常。每场景拼接测试视频帧后求 ROC AUC×100，再取七场景宏平均；标签取配对 `.npy`。与 768 维实验逐帧键、标签、数据指纹配对核验。
- 两张 GPU 各运行一个场景，结束后立即从待运行队列领取下一场景；启动前检测显存，轮询间隔 2 秒。日志、逐帧分数和核验报告留在本目录。

## 运行前参数核算

实际 PyTorch 模块计数：学生 **8,172,288**，OCBE **4,770,368**，可训练合计 **12,942,656**。768 维对照合计 **30,248,000**，预计减少 **17,305,344（57.21%）**；192 维版本合计 **7,718,336**。三版均不计冻结教师、YOLO 行为支路和 KNN 数据库。384 维学生产生 12 个 `[batch,256,768]` 输出。

## 限制

仅 seed=42 和一个中间宽度点，无法估计随机性或证明最优宽度；GPU 完成时间不等于无人机端推理延迟。
