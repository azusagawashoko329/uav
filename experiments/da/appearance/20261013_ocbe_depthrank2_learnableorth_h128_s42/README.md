# 可学习正交深度基：GL192＋OCBE hidden128＋rank2，seed42

## 研究问题

与 [固定 Mean+Trend 的 rank2 对照](../20261013_ocbe_depthrank2_hidden128_s42/README.md)比较：在其余模型、训练与评测全部保持一致时，让每组三层教师 tap 到两个深度方向的 2×3 矩阵从正常训练数据中学习，能否改善七场景 AUC？这个实验只检验共享深度基是否值得学习，不改变三对一反向蒸馏边界或学生 block。

## 唯一变化与数学定义

四组相邻教师三层 **共用同一个六参数原始矩阵** `Q_raw∈R^(2×3)`，初始化为

```text
[ 1/√3   1/√3   1/√3 ]
[-1/√2     0     1/√2]
```

每次前向对两行做可微 Gram-Schmidt 正交归一化，得到实际乘在每组三层特征上的 `Q_eff`，故 `Q_eff Q_effᵀ=I₂`。采用硬约束是为了只比较“保留哪两个深度方向”，避免行缩放和秩坍缩影响解释；也不引入额外正交惩罚权重。与建议的 `L_orth=||QQᵀ−I₂||²_F` 目标相同，但本实验用精确约束实现。固定版的逐 tap 仿射 LayerNorm、`6144→128→64` OCBE 融合、四 block Global-Local 192 学生、12 个重建头均不变；可训练参数仅多 **6** 个，总计 **3,761,222**（不含冻结教师及行为分支）。

`Q_raw` 和 `Q_eff` 的数值不单独代表判别价值：与后续线性融合层存在重参数化自由度。因此训练后还要比较行空间投影矩阵 `P=Q_effᵀQ_eff`、它与固定 `P_fixed` 的主夹角、正交误差和奇异值。主夹角为零表示保留的二维子空间未变，即使两行系数已旋转。会保存每个场景的 Q 训练轨迹，避免只看最终值。

## 固定训练与评测

- 冻结 DINOv3 ViT-B/16，12 个教师 patch tap；相邻三层教师对应一个学生 block，按深到浅反向对齐，group-balanced top-5 cosine loss、alpha=0.5 不变。
- Drone-Anomaly 七场景独立训练、独立测试；正常帧训练，seed=42，15 epoch，batch=64，256×256，AdamW＋OneCycleLR，max_lr=5e-4，weight_decay=0.05。两张 GPU 动态领取场景；每场景独立初始化全部可训练权重。
- 测试每帧分数为 12 个重建头的 top-5 patch cosine distance 平均，越大越异常；按场景汇总测试视频帧与配对 `.npy` 标签算 ROC AUC×100，七场景做宏平均。与固定 rank2 对照核对帧键、标签和划分指纹。

## 判读限制

本实验用训练集正常帧学习 Q，不以测试异常标签训练。若 AUC 改善但主夹角接近零，不能宣称模型学到了新的深度子空间；可能只是行基旋转或优化轨迹变化。若主夹角变大但 AUC 未提高，说明正常数据驱动的方向不一定更有利于异常判别。单 seed 42 只能给出初步证据，后续应结合 seed43 复核。

## 结果与复盘

七场景均完成 15 epoch，逐帧分数、原始测试标签、数据划分指纹和固定 rank2 对照均通过复核。可学习版外观分支宏平均 AUC 为 **82.7591**，固定版为 **82.7351**，仅高 **0.0240 个百分点**；3 个场景上升、4 个场景下降。完整场景表与复核细节见 [结果报告](results/summary.md)，数值和最终 Q 见 [summary.json](results/summary.json)。

有效二维子空间相对固定 Mean+Trend 的主夹角介于 **0.799°–5.299°**，平均 **3.046°**：网络确实改变了保留的方向，但幅度有限，并未对应一致的 AUC 改善。正交误差低于 `1.5e-7` 来自前向 Gram-Schmidt 硬约束，不能解释为自行学得正交。第 15 个 epoch 训练损失只在 bike 比固定版更低，而该场景 AUC 还微降。当前单种子证据支持**固定 Mean+Trend 是足够强的低参数先验**；暂不支持可学习 Q 有可靠收益。六个参数与下游融合层共同训练，AUC 微小变化不能独立归因于 Q；要判断稳定性仍需复现实验种子。
