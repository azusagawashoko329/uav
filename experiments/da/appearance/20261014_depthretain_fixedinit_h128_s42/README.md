# 教师深度信息保留约束：固定 Mean+Trend 起点，seed42

## 问题与方法

原可学习 Q 在固定与随机初值下终点相距约 68°，表明现有蒸馏损失未充分确定保留的二维深度子空间。本实验从固定 Mean+Trend 初始化 Q；配对实验从随机正交 Q 初始化，其余设置一致。目标是检验新增的、只使用正常训练帧教师特征的信息保留目标，能否让两种起点收敛到同一**行子空间**，同时保持异常 AUC。

对每组三层归一化教师 patch 特征 `X∈R^(3×768)`，从每场景 16 张正常训练帧的[已登记深度探针](../20261013_ocbe_depthrank2_hidden128_s42/results/depth_energy_probe.json)取四组 `3×3` Gram 矩阵均值 `C`。`Q_eff Q_effᵀ=I₂`，新增 `L_retain=1−tr(Q_eff C Q_effᵀ)/tr(C)`。它等价于最小化三层特征在 rank2 投影后丢失的平均平方能量。若第二与第三特征值有间隔，其全局最优**二维子空间**是 `C` 的前两特征向量张成的平面；行基可旋转，不比较单行系数的相等性。

先用 16 帧探针只训练 Q 200 个 Adam 步（lr=0.01）；随后 Q 与 OCBE、学生一起训练 15 epoch，联合损失为原 group-balanced top-5 cosine 蒸馏损失加 `1.0×L_retain`。联合训练时的 `C` 每个 batch 都由该场景**实际正常训练帧**的冻结教师特征重新计算，按四组三层特征的 Gram 均值汇总，避免仅由 16 帧探针决定最终方向。有效 Q 每步仍由可微 Gram-Schmidt 保持正交。学生 GL192 四 block、OCBE hidden128/code64、四组三对一对齐、12 个重建头均不变。两种初始 Q 各跑 Drone-Anomaly 七场景，场景配对在**同一物理 GPU** 上先后运行，空闲 GPU 动态领取下一组场景。

## 判定口径与限制

先核对两种初值在 Q 单独训练后、15 epoch 后的子空间夹角及信息保留率；再逐帧比较 ROC AUC×100，分数为 12 头 top-5 patch cosine distance 的均值，越大越异常。正常帧仅用于训练和确定 `C`，异常标签只用于原测试评测。目标是七场景配对终点都相距不超过 5°，并客观报告相对旧固定 Q / 随机 Q 的 AUC 变化。

**该约束定义的是正常教师特征能量，不保证与异常 AUC 同向。** Q 预训练的 `C` 只来自每场景 16 张正常帧，联合训练的 `C` 使用全部参与蒸馏的正常 batch；仍需多随机起点才能确认泛化。两个实验的 Q 均有六个原始可训练系数，有效参数经正交化；OCBE＋学生总可训练数仍为 3,761,222，不含冻结教师、行为分支和 KNN。

## 结果与复核（2026-10-14）

详见[七场景配对结果](results/summary.md)。14 次运行全部完成；固定初值版宏平均帧 AUC 82.6903，比旧固定 Q 82.7351 低 0.0448 个百分点。两种初值最终保留同一个二维平面（七场景最大夹角 0.0052°），但随机初值版宏平均仅 82.5673；故本目标解决了 Q 子空间初始化依赖，未改善异常检测 AUC。逐帧标签、划分指纹、训练轮数、参数量和 Q 正交性已复核。
