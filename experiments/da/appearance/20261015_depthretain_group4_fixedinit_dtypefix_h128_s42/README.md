# 四组独立深度 Q：Mean+Trend 初始化，seed42

## 问题与唯一结构变化

比较[共享 Q 的固定初值对照](../20261014_depthretain_fixedinit_h128_s42/results/summary.md)：12 层教师分成四组三层，每组是否应使用自己独立的可学习 `2×3` 矩阵 `Q_g`？原方案只有一个 `Q`，从四组 Gram 矩阵的均值学习一个公共二维平面；本方案有四个 `Q_g`，各压缩本组的三层特征。每个 `Q_g` 都从 Mean+Trend 初始化，由可微 Gram–Schmidt 保持两行正交。除 Q 的共享方式外，GL192 四 block 学生、OCBE hidden128/code64、三教师层对一学生层的反向蒸馏对齐、12 个输出头和 top-5 余弦蒸馏损失保持相同。

每场景分别训练，不跨场景混合权重。同一 Q 在本组三层的所有 patch、768 个通道共用；四组之间不共享 Q。按单个 patch 计，四组的三层 `3×768` 各变成 `2×768`，拼接为 `6144`，再经 `Linear 6144→128→GELU→Linear 128→64`，送入学生。总可训练参数预计 3,761,240，比共享可学习 Q 多 18 个。

## 分组 C 与损失

对正常训练帧教师特征按通道 LayerNorm 后，取每组每个 patch/通道上的三维层向量 `x_g`，定义各自的 `C_g=E[x_g x_gᵀ]`。四组 `C_g` **不先平均**。每个 Q 只面对本组统计量，保留损失为

`L_retain=1−Σ_g tr(Q_g C_g Q_gᵀ)/Σ_g tr(C_g)`，其中 `Q_g Q_gᵀ=I₂`。

若四个 Q 被设为同一个 Q，此式退化成共享 Q 版本的原损失，因此损失规模可直接比较。先从[已有 16 正常帧教师探针](../20261013_ocbe_depthrank2_hidden128_s42/results/depth_energy_probe.json)的四个原始 Gram 矩阵对四个 Q 单独优化 300 个 Adam 步（lr=0.01）；随后正式训练 15 epoch，每个 batch 分别更新四个 `C_g`，优化 `L_total=L_group_balanced_top5+1.0×L_retain`。教师冻结；异常标签只用于测试帧 ROC AUC×100，分数为 12 个重建头 top-5 patch 余弦距离的均值，分数越大越异常。共享 Q 对照使用 200 步 Q 预训练；预检中它在 200 步已收敛，而本实验随机四组 Q 的最慢一组需要约 300 步。此差异需在 AUC 比较时注明。

预检同一探针显示：七场景内四组最优二维平面两两最大夹角约 18–22°。独立 Q 对探针正常特征能量的理论增益仅 0.216–0.347 个百分点；因此存在组别方向差异，但 AUC 是否改善未知。预先判定以七场景逐帧 AUC 宏平均及逐场景变化为主，分组 Q 的最终平面角度和保留能量为机制指标。与[随机初值配对版本](../20261015_depthretain_group4_randominit_dtypefix_h128_s42/README.md)在同一物理 GPU 上先后运行；两张卡动态领取七场景，共 14 次训练。

## 限制

正常特征能量不是异常 AUC 代理。Q 单独预训练仅用每场景 16 张正常帧，联合训练使用各 batch 的正常帧；仅 seed42 和一次随机 Q 抽样，不足以判断跨种子稳健性。不同 Q 的行基可在各自平面内旋转/反射，比较时以行空间投影而非六个原始数逐个相等为准。
