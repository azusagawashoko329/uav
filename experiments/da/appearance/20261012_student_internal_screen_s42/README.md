# 学生内部结构筛选（小型模块实验）

## 研究问题

在四个学生 block、12 个教师输出的反向蒸馏结构中，学生内部状态是否可以从教师的 768 维缩小，或用较少的 MLP/局部混合计算替代完整 block，同时保留教师语义输出空间？

## 本次范围

本实验只做模块级筛选，不进行七场景训练和 AUC 结论。比较 `MLP ratio=4/2`、内部宽度 `768/512/384`、GQA、朴素线性注意力和 2D depthwise 局部混合的参数量及单步前向/反向开销。另从少量正常 highway 帧提取 12 层 DINOv3 patch 特征，估计教师特征的 PCA 有效秩，为内部宽度选择提供依据。

## 数学假设

学生内部状态记为 `X in R^(N x d_s)`，每个蒸馏头 `H_l in R^(d_s x 768)` 输出 `T_hat_l = H_l X`。Top-k cosine loss 只约束输出到 768 维教师空间的结果，不要求 `d_s=768` 或 block 结构镜像教师；但 `rank(H_l) <= d_s`，因此需要用正常教师特征的有效秩检验宽度下界。

## 固定设置

- 数据：Drone-Anomaly 的 highway 正常训练帧，仅取少量样本做特征秩分析。
- 教师：冻结 DINOv3 ViT-B/16，12 个 patch 输出，输入 256x256（256 patch tokens）。
- benchmark：`B=1,N=256`，CUDA，独立进程逐个测量，默认 30 次 warmup、100 次计时。
- 结果不代表训练收敛或 AUC；正式结论需要按协议建立新的七场景实验。

## 观察与限制

前一轮临时 benchmark 已提示 MLP ratio=2 是低风险候选，朴素线性注意力在 N=256 时可能不占优；本目录的脚本将把这些观察固化为可复查结果。GQA 若没有目标硬件上的融合 kernel，不把 PyTorch 自定义实现的耗时直接解释为结构结论。
