> 下面 5 张表是 **MADViT**(原论文复现)的结果,**不是我的方法**。frame-level AUC%,全局 concat。
> 表1–5 = 5 套权重(同打分、换权重竖向对比)。每行最高/次高在 11 个打分变体列间加粗。
> 场景顺序:**highway / farmland / bike / solar / vehicle / crossroads / railway**。

**权重(训练目标)**:LL=末层两 token 的 KL;ML=12 层 patch 全片摊平余弦(论文 Multi-layer);Full=token KL + 全层余弦(论文 Full);LLTopk=token KL + 每层逐 patch 余弦差 top-5 均值;Topk=仅逐 patch top-5。

**列(打分)**:`ll`=末层两 token KL;`ml`=12 层摊平余弦均值;`full`=ll+ml;`pmean_all`=逐 patch 余弦差→196 均值→层均值;`pmax_last`=逐 patch→空间 MAX→仅末层;`pmax_all`=→MAX→12 层均值;`ptopk_all`=→每层 top-5 均值→层均值;`zfuse_ll_*`=ll 与该 patch 分数各自 z-score 等权相加。
